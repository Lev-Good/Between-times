# פתיחה מרחוק מטלפון כשר

## ארכיטקטורה
טלפון כשר → קו ימות המשיח (שלוחת API) → `gas/RemoteUnlock.gs` (Apps Script) ← המחשב שואב כל 30 שניות.

- המחשב **אינו מקבל חיבורים נכנסים**; הוא רק פונה החוצה ב-HTTPS.
- בקשת הבדיקה חתומה ב-HMAC-SHA256 עם מפתח המכשיר (נוצר במחשב, נשמר בהגדרות המוגנות, אינו מיוצא בגיבוי ואינו מועבר לממשק).
- כל פקודה חתומה וקשורה ל-nonce של אותה בקשה — אי אפשר להשמיע מחדש תשובה ישנה. פקודות פגות אחרי 10 דקות בשרת.
- הקוד בטלפון נשמר בשרת כ-HMAC בלבד, ונבדק שם. 5 טעויות → נעילה של 15 דקות (מוכפלת בכל נעילה, עד 24 שעות).

## הפעלה
1. פורסים את `PasswordRecovery.gs` ו-`RemoteUnlock.gs` באותו פרויקט Apps Script (Web app, Anyone). מומלץ עותק משלכם — מי שמפעיל את הסקריפט רואה את המפתחות.
2. בהגדרות ← פתיחה מרחוק: מזינים קוד (4–8 ספרות) וכתובת השרת (ריק = ברירת המחדל) ← "שמירה והפעלה".
3. בקו ימות המשיח יוצרים שלוחת API ומציבים `api_link` לכתובת שמוצגת בהגדרות (`…/exec?a=ivr&d=<מזהה>`).

## תפריט הטלפון
קוד גישה ← 1 דקות · 2 עד שעה (HHMM) · 3 משעה עד שעה · 4 ללא הגבלה · 7 נעילה.
שעות מתפרשות לפי שעון המחשב; "עד שעה" = המופע הבא של השעה.

## התנהגות במחשב
- פתיחה גוברת על הלוח ועל מכסת הזמן היומית, ושורדת הפעלה מחדש (עד שתסתיים או שיינעל מהטלפון).
- נעילה מהטלפון = "נעל עכשיו" (נפתח בסיסמה או שוב מהטלפון).
- שותף אחריות עם "חייב אישור" → פקודות פתיחה נדחות ('remote-refused' ביומן). תקופת צינון → תחילת הפתיחה מתעכבת בהתאם.
