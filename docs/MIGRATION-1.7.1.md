# Migration and Release Gate: 1.7.0 → 1.7.1

## Schema Migration

**אין מיגרציה.** `schemaVersion` נשאר `2`, אין שדות חדשים ואין שינוי במבנה
הנתונים. הלוח השבועי, החריגים, הסיסמה, שחזור הסיסמה, שותף האחריות, התוכנות
המאושרות, האתרים, סייר הקבצים, הפרופילים, ערכת הנושא והרקע — כולם נשמרים כמו
שהם. גם `usage.json` (מכסת השימוש היומית) והרישיון אינם מושפעים.

זו עליית **פאץ'** לתיקון תקלה בלבד.

## שינויי התנהגות שההורה צריך להכיר

1. **עדכון מתוך התוכנה מבקש הרשאות (UAC).** כשהתוכנה רצה בלי הרשאות מנהל,
   ההתקנה מציגה חלון אישור של Windows לפני שהיא מתחילה. בחשבון ילדים (שאינו
   מנהל) ההורה יצטרך לאשר את הבקשה — או להזין סיסמת מנהל. קודם לכן ההתקנה
   לא הותקנה כלל, בשקט.
2. **כשל בהעלאת המתקין מדווח ולא משאיר את המשתמש בלי תוכנה.** אם בקשת
   ההרשאות מבוטלת, מוצגת הודעה ברורה והתוכנה **נשארת פתוחה**. קודם לכן היא
   נסגרה ודיווחה הצלחה, בעוד דבר לא הותקן.
3. **הרצה עם הרשאות מנהל — בלי שינוי:** ההתקנה נשארת שקטה ולא מוצג UAC.
4. **הסרה** מתוך התוכנה עוברת עכשיו גם היא דרך בקשת הרשאות באותם תנאים.

## ⚠️ התקנה ידנית חד-פעמית — הכרחית

התיקון **עצמו** יושב בתוכנה. לכן גרסה קיימת מותקנת (1.7.0 ומטה) אינה יכולה
לעדכן את עצמה אל התיקון: הקוד הפגום יושב אצלה ואינו יודע להרים הרשאות.

**יש להתקין את 1.7.1 פעם אחת ידנית** מעמוד ההורדות. מכאן והלאה העדכון
האוטומטי מתוך התוכנה יעבוד כרגיל.

## Upgrade Path

- התקנה מעל 1.7.0 (ומעל כל גרסה מ-1.5.8 ומעלה) נתמכת ואינה דורשת הסרה:
  המתקין מרים את איסור המחיקה לפני החלפת הקבצים, מזהה רישיון פורום קיים
  (`%ProgramData%\BenHazmanim\license.json`) ומדלג על מסך הרישיון, ושומר את
  ההגדרות המשותפות ואת העותק המוגן.
- אין פעולה ידנית נדרשת מהמשתמשים מלבד ההתקנה הידנית החד-פעמית שבסעיף הקודם.

## Release Procedure

לפי הנוהל המלא ב-[UPDATES-AND-SECURITY.md](UPDATES-AND-SECURITY.md), עם גרסה
`1.7.1` וסימון התג `v1.7.1`. **שימו לב לסדר המחייב:** תג ← Release ← דחיפת
`main` (כדי שלא ייווצר חלון שבו `version.json` מכריז על גרסה שאין לה Release).

## Mandatory VM Matrix (תוספות 1.7.1)

- **עדכון מתוך התוכנה בחשבון שאינו מנהל** — מופיע חלון UAC, מזינים סיסמת
  מנהל, ההתקנה משלימה, והתוכנה נפתחת מחדש בגרסה החדשה. **זה התרחיש המרכזי
  שתוקן בגרסה הזו.**
- **ביטול חלון ה-UAC** — מוצגת הודעת שגיאה, והתוכנה **אינה** נסגרת ושומרת
  על מצבה (כולל שהשומר-השער לא מפסיק לאכוף אחרי הכשל).
- **עדכון בחשבון מנהל** — שקט, בלי UAC (וידוא שלא נוצר UAC מיותר).
- **הסרה מתוך התוכנה** בשני סוגי החשבונות.
- שימור ההגדרות, הסיסמה והרישיון אחרי העדכון.
