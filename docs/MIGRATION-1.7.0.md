# Migration and Release Gate: 1.6.5 → 1.7.0

## Schema Migration

**`schemaVersion` נשאר `2` — אין מיגרציית נתונים.** העלאת הגדרות מ-1.6.5 היא
שקופה ומוסיפה בלבד (בדיוק כמו שתואר ב-[MIGRATION-1.6.0.md](MIGRATION-1.6.0.md)):

- הלוח השבועי, החריגים, הסיסמה, שחזור הסיסמה, שותף האחריות, התוכנות המאושרות,
  האתרים, סייר הקבצים, הפרופילים, ערכת הנושא והרקע — כולם נשמרים כמו שהם.
- מכסה יומית שהוגדרה בגרסה קודמת נשמרת עם מספר הדקות שהיה בה.
- `usage.json` (מכסת השימוש היומית) הוא קובץ חדש לחלוטין — היום הראשון אחרי
  העדכון מתחיל מאפס שניות שימוש, ואין "חוב" היסטורי מצטבר.

### תיקון הגירה אחד שחובה להכיר

בגרסאות עד 1.6.5 אפשר היה **להדליק מכסת זמן יומית בלי סיסמת הורה**. מכסה כזו
לא הייתה נאכפת ממילא (האכיפה דורשת סיסמה), אבל החל מ-1.7.0 היא גם נחשבת
"מדיניות חסימה" ולכן הייתה חוסמת **כל** שמירת הגדרות אצל אותו הורה.

לכן בהעלאת ההגדרות מתבצע תיקון חד-פעמי ושקוף: אם קיימת מכסה מופעלת בלי סיסמת
הורה — המכסה **מכובה** (מספר הדקות נשמר), והאירוע נרשם ביומן הפעילות כ-
`settings-migrated` עם `repair: "dailyLimit-without-pin"`. המשמעות בפועל אפס, כי
בלי סיסמה המכסה אינה נאכפת בכל מקרה. מכוסה בבדיקה
`load: מכסת זמן יומית בלי סיסמה מכובה בהעלאה` ב-`test/main-flow.test.js`.

## שינויי התנהגות שההורה צריך להכיר

1. **מכסת זמן יומית דורשת סיסמת הורה.** הפעלה בלי סיסמה נדחית עם הסבר, וכשהמכסה
   פעילה אי אפשר להסיר את הסיסמה (אחרת ההגבלה נעלמה בשקט). כדי להסיר סיסמה —
   קודם מכבים את המכסה.
2. **רשימת האתרים יכולה להיות הפוכה.** במצב "כל האתרים פתוחים חוץ מהרשימה"
   נפתח דפדפן מוגבל עם שורת כתובת. החסימה חלה **על הדפדפן של התוכנה בלבד** —
   לא על דפדפנים אחרים במחשב (עבורם יש את לוח הזמנים). הערה זו מופיעה גם במדריך
   ובשאלות הנפוצות.
3. **אתר מאושר והדפדפן המוגבל נשארים שמישים בזמן חסימה.** מסך החסימה מוסתר
   אוטומטית כשחלון שלהם בחזית וחוזר מיד עם עזיבתו — בלי "זמן חסד".
4. **התוכנה לא נפתחת על המסך באתחול.** הפעלה עם Windows נשארת שקטה במגש; הפעלה
   יזומה של המשתמש (קיצור דרך/תפריט התחל) פותחת את ההגדרות כרגיל.

## Upgrade Path

- ההתקנה מעל 1.6.5 נתמכת ואינה דורשת הסרה: המתקין מרים את איסור המחיקה לפני
  החלפת הקבצים, מזהה רישיון פורום קיים (`%ProgramData%\BenHazmanim\license.json`)
  ומדלג על מסך הרישיון, ושומר את ההגדרות המשותפות והעותק המוגן.
- `usage.json` נוצר מחדש בתיקייה המוגנת (בהתקנה מנוהלת) בהרצה הראשונה.
- אין צורך בפעולה ידנית מצד המשתמשים. שדרוג חד-פעמי נדרש רק מגרסה `1.5.7`
  ומטה (ראו [MIGRATION-1.6.0.md](MIGRATION-1.6.0.md) ו-`README.md`).

## Release Procedure

נוהל השחרור המלא נמצא ב-[UPDATES-AND-SECURITY.md](UPDATES-AND-SECURITY.md).
להלן השלבים לגרסה הזו, לפי הסדר המחייב:

1. **גרסה** — `package.json` עודכן ל-`1.7.0`, וגם גרסאות ברירת המחדל המוצגות
   ב-`renderer/index.html` (`#version`, `#version2`).
2. **בדיקות** — `npm test` חייב להסתיים ב-**0 כשלים** (ראה "Automated Gate" למטה).
3. **בנייה** — `npm run dist` ← נוצר `dist\Setup.1.7.0.exe`.
4. **טביעת אצבע** —
   `(Get-FileHash .\dist\Setup.1.7.0.exe -Algorithm SHA256).Hash.ToLower()`.
5. **`version.json`** — מעדכנים `version` ל-`1.7.0`, את ה-`sha256` **משלב 4
   בלבד**, ואת ה-`notes` (נוסח מוצע למטה). **אין לפרסם `version.json` עם גרסה
   חדשה וטביעת אצבע שאינה של הקובץ שנבנה** — כל לקוח מותקן יוריד את המתקין,
   ייכשל באימות ה-SHA-256 ויבטל את העדכון.
6. **Commit ו-Push** — רק הקבצים של השחרור (ראו הרשימה ב-
   `UPDATES-AND-SECURITY.md`; אין להשתמש ב-`git add .`).
7. **Release ב-GitHub** — Tag `v1.7.0`, העלאת `Setup.1.7.0.exe`, פרסום.

### נוסח מוצע ל-`notes` ב-`version.json`

> גרסה 1.7.0 — שליטה ממוקדת באינטרנט וזמן שימוש מוגבל ביום: רשימת האתרים
> בהפוכה ("כל האתרים פתוחים חוץ מהרשימה") עם דפדפן מוגבל חדש בעל שורת כתובת,
> אתר מאושר ודפדפן מוגבל שנשארים שמישים בזמן חסימה, מכסת זמן שימוש יומית
> (נשמרת גם אחרי אתחול, מתאפסת בחצות, דורשת סיסמת הורה) עם התראה וספירה לאחור
> לפני גמר המכסה, ותיקון שלפיו התוכנה אינה נפתחת על המסך באתחול של Windows.

## Mandatory VM Matrix (1.7.0 additions)

בנוסף לכל המטריצה הקיימת ב-[MIGRATION-1.6.0.md](MIGRATION-1.6.0.md), יש לבדוק
ב-VM חד-פעמית:

### מכסת זמן שימוש יומית
- מכסה קצרה (5 דקות) לאורך יום שלם, כולל **מעבר חצות** — שהמכסה מתאפסת.
- אתחול מחשב וסגירה/פתיחה של התוכנה בתוך היום — שהזמן המצטבר נשמר.
- שינה/הערה של המחשב — שהזמן הלא-אמיתי אינו נספר.
- התראת הווינדוס והבאנר לפני גמר המכסה, פעם אחת בלבד בכל חלון אזהרה.
- מסך החסימה בגמר המכסה: הסבר, ספירה לאחור עד חצות, ופתיחה בסיסמת ההורה
  שנשארת בתוקף עד חצות.
- כיבוי המכסה ואז הסרת הסיסמה (עובד), ולהפך (נחסם עם הסבר).

### דפדפן מוגבל במצב רשימת חסימה
- גלישה לאתרים אמיתיים שמורים ולאתרים שברשימה, כולל אתר שמפנה לאתר חסום,
  פתיחת קישור בחלון חדש, `target=_blank`, ו**הורדת קובץ** (נחסמת).
- בקשת הרשאה (מצלמה/מיקרופון/מיקום) — נדחית.
- תת-מתחמים של אתר חסום, אתר עם סיומת דומה (`example.com.evil.org`), ופורט
  אחר — לפי התנהגות ההשוואה המתועדת.
- כתובת בית מותאמת אישית, וגלישה גם כשהמחשב חסום (החלון לא נעלם מאחורי
  מסך החסימה).

### אתחול שקט
- כמה אתחולים רצופים של Windows — אין חלון קופץ על המסך.
- הפעלה יזומה של המשתמש — חלון ההגדרות נפתח כרגיל.
- הודעת "התוכנה פועלת ברקע" — פעם אחת בלבד, בכל ההתקנה.

### שדרוג
- התקנה מעל 1.6.5 עם מכסה מופעלת **בלי סיסמה** — ההגדרות נשמרות, המכסה מכובה
  בהעלאה, והיומן מתעד `settings-migrated`.
- התקנה מעל 1.6.5 עם רישיון פורום ולוח מוגדר — הרישיון וההגדרות נשמרים.
