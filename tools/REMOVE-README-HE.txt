============================================================
  הוראות שימוש — סקריפט הסרת חירום של "בין הזמנים"
  (remove-benhazmanim.cmd)
============================================================

מה הסקריפט עושה
------------------------------------------------------------
הסקריפט מסיר את התוכנה "בין הזמנים - ניהול זמן מחשב" מהמחשב
לגמרי — בלי צורך בסיסמת ההורה. הוא מיועד למקרי חירום/תמיכה,
כשהמחשב תקוע (מסך חסימה), המשתמש שכח את הסיסמה, אין גישה
לאינטרנט לשחזור, או שהתוכנה לא מוסרת בדרך הרגילה.

הסקריפט פועל בשני מצבים (Dual-Mode):
1. בתוך מערכת Windows פעילה (Online Mode).
2. מתוך סביבת השחזור של Windows באמצעות שורת הפקודה
   (WinRE Offline Mode) — למקרים שבהם מסך החסימה מונע גישה.

חשוב לדעת
------------------------------------------------------------
* הסקריפט מוחק את התוכנה ואת כל ההגדרות (לוחות זמנים,
  סיסמת ההורה) לצמיתות — אין דרך לשחזר אחר כך. יש להשתמש
  בו רק במקרי חירום או באישור בעל התוכנה.
* נדרשת הרשאת מנהל (ב-Windows רגיל: מסך UAC; ב-WinRE:
  סיסמת ה-Windows של המנהל).

============================================================
שיטה א': הרצה מתוך סביבת שחזור (WinRE) — במצב חסימה
============================================================
אם המחשב חסום במסך החסימה ואינכם יכולים להגיע לשולחן העבודה:

1. העתיקו את remove-benhazmanim.cmd לדיסק-און-קי מכל מחשב אחר.
2. במחשב החסום, לחצו על סמל הכיבוי במסך הנעילה/הכניסה,
   החזיקו את מקש Shift במקלדת ברציפות ולחצו על "הפעל מחדש" (Restart).
3. במסך הכחול שיופיע, בחרו:
   "פתרון בעיות" (Troubleshoot)
   -> "אפשרויות מתקדמות" (Advanced options)
   -> "שורת הפקודה" (Command Prompt).
4. המחשב יאתחל ויבקש לבחור את חשבון המנהל ולהזין את סיסמת ה-Windows שלו.
   (הערה: אם מופעלת במחשב הצפנת BitLocker, המערכת תבקש את מפתח
   השחזור של BitLocker בן 48 ספרות, הנמצא בחשבון המיקרוסופט שלכם בכתובת:
   https://account.microsoft.com/devices/recoverykey).
5. ייפתח חלון שחור של שורת הפקודה (X:\windows\system32).
6. חברו את הדיסק-און-קי למחשב, אתרו את אות הכונן שלו (למשל D: או E:),
   והפעילו את הסקריפט:
   E:\remove-benhazmanim.cmd
7. הסקריפט יאתר את כונן הווינדוס, ימחק את המשימות והקבצים.
8. בסיום, הקלידו exit ולחצו Enter, ובחרו "המשך ל-Windows".
   המחשב ייפתח נקי וחופשי לחלוטין!

============================================================
שיטה ב': חילוץ ידני ב-WinRE ללא דיסק-און-קי (5 פקודות)
============================================================
אם ננעלתם בסביבת שחזור ואין לכם דיסק-און-קי בהישג יד:
בחלון שורת הפקודה של סביבת השחזור, הקלידו את הפקודות הבאות
(שתי פקודות ה-icacls חובה — התוכנה מגינה על התיקיות מפני מחיקה,
ובלעדיהן rmdir ייכשל עם "Access is denied"):

del /f /q C:\Windows\System32\Tasks\BenHazmanim*
icacls "C:\Program Files\ben-hazmanim" /reset /T /C /Q
icacls "C:\ProgramData\BenHazmanim" /reset /T /C /Q
rmdir /s /q "C:\Program Files\ben-hazmanim"
rmdir /s /q "C:\ProgramData\BenHazmanim"
exit

(הערה: בסביבת השחזור כונן הווינדוס מקבל לעיתים אות אחרת, כגון D:.
בדקו עם הפקודה  dir D:\  — הכונן הנכון הוא זה שמכיל תיקיית Windows —
והחליפו את C: באות המתאימה).
לאחר מכן המשיכו לווינדוס כרגיל.

============================================================
שיטה ג': הרצה ב-Windows פעיל (לפני חסימה)
============================================================
1. מעתיקים את remove-benhazmanim.cmd למחשב.
2. לוחצים עליו פעמיים (או מקש ימני → "הפעל כמנהל").
3. מאשרים את חלון UAC.
4. הסקריפט עוצר את התהליכים ומוחק את כל מרכיבי התוכנה.
============================================================
